Core features

From gesture capture to meaningful progress.

The six core parts of the approved GabaySenyas learning workflow.

Capture and detection

Uses a webcam to capture hand gestures and detect hand landmarks in real time.

Sequence analysis

Processes landmark sequences with a machine-learning model to recognize defined FSL signs.

Accuracy scoring

Compares each attempt with a validated reference sequence to generate a signing score.

Adaptive learning

Adjusts lesson order and difficulty based on the learner’s performance history.

Lesson library

Provides structured, difficulty-tiered FSL vocabulary with demonstration videos or images.

Performance analytics

Tracks learner progress and presents useful performance information to learners and administrators.
